# Huffman Coding Compression Tool

## Overview
This project implements the **Huffman Coding Algorithm**, a popular method used for lossless data compression. It assigns variable-length codes to input characters based on their frequencies.

## Features
- Efficient data compression and decompression.
- Generates a frequency table for input characters.
- Builds a Huffman Tree to assign binary codes.

## How to Use
1. Clone the repository:
   `git clone https://github.com/YourUsername/Huffman-Coding.git`
2. Open the project folder.
3. Run the script/program:
   - For Python: `python huffman.py`
   - For C++: `g++ huffman.cpp -o huffman && ./huffman`

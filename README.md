# Huffman Coding Project

## Description
Ye project Huffman Coding algorithm ka use karke data compress karta hai. Maine ise Notepad ka use karke banaya hai.

## Kaise Chalayein (How to Run)
1. Sabse pehle is repository ko download ya clone karein.
2. Apne terminal par `python filename.py` (ya jo bhi aapki language hai) command chalayein.

## Features
- Lossless data compression.
- Binary tree visualization.
